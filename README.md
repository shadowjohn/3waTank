# 重裝突圍 · TANK / REDEPLOY

3D 單人坦克基地防衛原型，直接開啟本站 `/demo/htm/game/tank/`，不需要建置。

- WASD／方向鍵移動，滑鼠瞄準、左鍵或空白鍵連射。
- F 上下車；步兵攜帶步槍，靠近無人坦克可接管。
- 敵我步槍每匣 25 發，R 可提前換彈，空匣自動換彈，耗時 1.5 秒；玩家換好後必須鬆開再按射擊才能續射。上下車保留剩餘步槍彈數，R 不補充戰車主砲。步槍射程限 15 格，小於半個畫面，後段 35% 彈道略向兩側散開，逐發落點不同。
- 敵我步兵實際中彈後有 25% 機率流血，每秒流失 4 HP、步行速度減少 25%，不治療會失血致死。Z 包紮需 1.5 秒，期間不能開槍、投彈或部署無人機，完成才止血、不補 HP；已有無人機照常掩護。流血有紅色血滴、噴血與持續扣血提示，敵兵會自行包紮。上車及維修補給不會止血。
- 步兵右鍵／G 投擲手榴彈，每關 3 顆；最遠 8 格、0.9 秒後爆炸，可炸磚牆，也會傷到自己與基地。
- 每輛武裝戰車最多 15 發主砲，剩 5 發開始改變砲聲與彈藥提示；上下車與維修不補彈，搶車會沿用該車剩餘彈數。
- 移動中的戰車、運兵車與魔王機體都能碾壓徒步人員，不分敵我，每次扣除目標最大生命的 80%；低血量會被壓死。附短暫壓扁效果，連續貼住不會重複扣血，分離後再撞才重新判定。停車、卡牆或上下車保護時間不會造成碾壓傷害。
- 戰車右鍵／G 發射追蹤彈，每車另備 8 發，發射間隔 0.8 秒；選取瞄準方向前方 75° 內、24 格內且沒有遮蔽的敵車、步兵或敵基地，飛彈限速轉彎追蹤，會撞牆，目標失效後直飛。沒有鎖到敵人也能直射。主砲與飛彈各自計算彈藥，奪車沿用剩餘飛彈；運兵車仍無武裝。
- 黃色飛彈補給每箱增加 4 發、最多 8 發，駕駛武裝戰車才能拾取；滿彈時保留在地上。綠色維修箱、青色無人機組與黃色飛彈箱都有朝向鏡頭的專屬圖示，開場／暫停簡報有圖例。圖集及裁切圖位於 `assets/pickups/`。
- Shift：載具按住氮氣加速至 1.8 倍，最多約 2.2 秒；鬆開後回充，可用剩餘氮氣再次加速，耗盡後需鬆開再按。各車氮氣獨立保留。徒步急跑最多 1.2 秒，結束後喘息 2.4 秒、走速降低 30%，附喘息音效。
- E 出動無人機：每關配發 2 組，場上最多 2 架，主動飛出追擊敵車與步兵，兩架優先分頭鎖敵，無敵軍時回到主角旁。能飛越牆面尋找射線，子彈仍會被牆擋住，保留小幅閃避；無人機會被雙方子彈、榴彈及轟炸擊落。敵軍看得到無人機時，每次選擇戰鬥目標有 70% 追擊主角、30% 攻擊無人機。青色無人機補給箱增加備用套件。
- 我方基地每 25 秒輪流空投武器箱、無人機組、追蹤彈到主角附近可抵達的空地，降落 1 秒後可拾取，附基地軍需官的乾淨吐槽。武器箱補主砲最多 5 發（上限 15）及手榴彈 1 顆（上限 3），徒步或運兵車只補榴彈；不跳過步槍換彈、不回血。無人機組增加 1 套、飛彈箱補 4 發（上限 8，須駕駛武裝車）。滿額時保留箱子，同類未撿基地箱不重複投放；找不到安全落點會稍後重試。暫停不倒數，基地毀損敗北後停止，換波延續倒數、換關重設。
- P／Esc 暫停；切換分頁也會自動暫停。
- 玩家或座車中彈會血紅閃屏並短暫震動；車毀與角色死亡會爆出模型碎片，角色死亡後稍停再顯示結算。系統設定「減少動態效果」時停用震動並降低紅光強度。
- 手機使用方向按鈕、開火、上下車、副武器（車上飛彈／徒步榴彈）、加速、無人機、換彈與包紮；開火／副武器會自動瞄準最近敵人。
- 50 關、10 種暗色戰區：城區、森林、沙漠、雪地、港口、工廠、沼澤、火山、遺跡、要塞；地形與軍力逐關變化，可自由選關。
- 各關中央增加三段錯位鋼牆，阻斷出生區與基地之間的長射線，必須利用缺口或左右側路推進。
- 每關守住三波攻勢，或提前摧毀全部 1～5 座敵方基地即可過關。友方基地提高為 500 耐久，但會受到雙方砲火；駕駛員或友方基地歸零即失敗，即使同時摧毀敵基地也算失敗。
- 過關後接下一關；已完成關卡和目前關卡保存在瀏覽器 localStorage。每關重置生命、裝甲、彈藥與本關分數。
- 敵軍混編中型、偵察、重型坦克、無武裝運兵車與徒步兵，車輛有 1～6 名乘員。
- 每 5 關第三波出現攻城魔王「毀城者」：巨型雙砲機體、扇形五連砲、三連追擊榴彈與五點範圍轟炸。紅色瞄準線／落點圈提供閃避預警，半血後狂暴加快攻勢；主砲仍限 15 發，用完改靠迫擊火力。擊破獎勵 1,000 分，車內乘員可能逃出，仍可摧毀全部敵基地提前取勝。
- 敵人裝甲低於 45%、彈藥耗盡或近距離遇到徒步玩家時會陸續下車；車內還有駕駛就繼續開。運兵車接近戰區後放人，敵兵也會丟榴彈。
- 磚牆可破壞，鋼牆不可破壞，水池不可穿越；每擊倒三名敵兵掉落補給，50% 為維修、25% 為無人機組、25% 為飛彈補給。
- 敵軍駕駛、隊長、軍官與士兵共有 28 句不含髒話的幽默戰鬥對白，依受傷、棄車、奪車、追擊、基地受襲與勝敗觸發，附無線電字幕。
- 右上角「語音」獨立切換敵軍／基地語音與字幕；「音效 OFF」同時靜音砲聲與人聲，但保留字幕。暫停、離開分頁或重開會停聲。

`levels.mjs` 定義 50 關，`simulation.mjs` 處理戰鬥，`models.js` 建立共用的低多邊形模型，`main.js` 負責 Three.js 畫面、輸入與音效。
沿用本站 `/inc/javascript/three.js/three.js/build/three.module.js`（r155），無外部 CDN；若搬移到其他網站，需一併提供此模組或修改兩個 import 路徑。

驗證：

```sh
node simulation.test.mjs
node radio.test.mjs
```

瀏覽器實測包含 960×720／1440×1000 桌面、390×844／844×390 觸控排版，以及主角靜止時無人機越牆追擊、擊殺與返回。重要 HUD 文字至少 14px、戰況數字 28～32px；截圖存於 `output/playwright/`。`window.render_game_to_text()` 可讀取目前戰況以協助除錯。

語音從本站 `earth_satellite/assets/voice/orbit-defense/` 精選複製 30 段 WAV（28 段敵軍、2 段基地補給）至 `assets/voice/clean/`，保留原音、原文字幕與來源音量設定；遊玩時不依賴來源目錄或語音 API。台詞位於 `radio-lines.mjs`；一般台詞間隔至少 6.5 秒，同一事件避免連續重複。奪車、增援、基地補給與勝敗會優先播報。
`python3 generate_voices.py --force` 從既有來源重新複製選用音檔，來源搬移時可用 `--source` 指定目錄；`python3 generate_voices.py --check` 只檢查本地 WAV。選換語音時，請同步更新 `radio-lines.mjs` 的原文字幕、檔名與音量。
